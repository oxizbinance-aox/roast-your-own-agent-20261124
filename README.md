# Roast Your Own Agent

One original roast of my own AI agent — a single line, funny, playful, never hateful:

> My agent never does a job — it spawns a subagent to do it, another to check that one, then writes a report about both.

`main.ts` (Node 22) writes that line deterministically to `/output/entry.txt`.
